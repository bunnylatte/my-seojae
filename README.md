# 🐰 담노트 DAM:NOTE

오늘의 생각, 기록, 좋아하는 것들을 차곡차곡 담아두는 나만의 노트예요. 굿노트처럼 공책을 꽂아두는 서재 화면에서 메모를 열고, 타로·덕질 일기·스터디 플래너 같은 템플릿으로 바로 정리할 수 있어요.

## 주요 기능
- 템플릿 16종: 빈 메모, To do list, 하루 일기, 스터디 플래너, 업무일지, 연구노트, 회의록, 주간 계획, 만다라트, 가계부, 운동 기록, 여행 계획, 독서 기록, 타로 정리, 덕질 일기, 영화·드라마 감상
- 직접 만든 양식을 "내 템플릿"으로 저장
- 폴더별 정리, 검색, 공책 표지 색상
- 사진 첨부(캡처 Ctrl+V, 파일 끌어다 놓기), 스티커·라벨
- 서식 그대로 복사 / 카톡용 텍스트 복사 / SNS 크기 이미지로 나눠 내보내기
- PDF 저장(브라우저 인쇄 → PDF로 저장)
- 인터넷 없이도 동작, 앱으로 설치 가능
- PC · 안드로이드 · 아이폰 모두 지원 (휴대폰에서는 SNS로 바로 공유)
- 처음 열면 사용 안내, 왼쪽 메뉴의 「💬 의견 보내기」로 의견 전달

## 데이터와 개인정보
- 메모와 사진은 **사용하는 사람의 브라우저 안에만** 저장돼요. 서버로 전송되거나 수집되지 않아요.
- 그래서 다른 PC·다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워질 수 있어요.
- 왼쪽 아래 「백업 저장」으로 사진까지 포함한 백업 파일을 만들 수 있고, 「백업 불러오기」로 다른 PC로 옮길 수 있어요.

## 사용법
👉 **https://bunnylatte.github.io/my-seojae/**

- **PC**: 크롬·엣지에서 열고, 주소창 오른쪽 「설치」 아이콘을 누르면 앱처럼 설치돼요.
- **안드로이드**: 크롬 ⋮ 메뉴 → 「앱 설치」 또는 「홈 화면에 추가」
- **아이폰·아이패드**: Safari 공유 버튼 → 「홈 화면에 추가」 (아이폰은 홈 화면에 추가해서 써야 메모가 오래 안전하게 보관돼요)
